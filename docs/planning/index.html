Activer la modification

Pour changer une date, la page écrit directement dans la file du robot sur GitHub. Il lui faut une clé d’accès, à créer une seule fois :

  1. Ouvrez github.com/settings/personal-access-tokens/new
  2. Nom : « Planning Petit Sac », expiration : 1 an
  3. Repository access : Only select repositories → petitsac-social
  4. Permissions → Repository permissions → Contents : Read and write
  5. Generate token, copiez la clé et collez-la ici

La clé reste uniquement dans ce navigateur. Elle ne donne accès qu’au dépôt du planning.
